# مسار شوية رياضة

مسار تفاعلي للصحة والرياضة لطلبة مدارس محافظة الظاهرة، ضمن برنامج الصحة المدرسية واليوم الرياضي الموحد «شوية رياضة».

- `index.html`: مسار الشهادة (محطات الشهادة، الاختبار، شهادة «سفير الصحة والرياضة»).
- `wisam.html`: مسار الوسام، يُفتح بعد الحصول على الشهادة.
